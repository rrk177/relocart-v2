# Relocart v2

Minimal-luxury redesign concept for relocart.ch. Static site: `index.html`, `style.css`, `main.js`, and `assets/`.

Open `index.html` through any static server to view it locally.

Before launch, set `FORM_ENDPOINT` at the top of `main.js` to a form endpoint that accepts a JSON POST (for example Formspree). Until then the form hands off to the visitor's email app.
